## Why the program restarted

The heavy-rebuild doctrine was amended after the first OWS-001 implementation to
restore mandatory multi-stage 3D interpretation and visual-review gates. The earlier
process relied on static generation and a four-image render set that was useful but
insufficient for peak-quality approval.

The revised procedure now blocks approval unless the structure passes:

1. a pre-rebuild visual baseline;
2. Visual Gate A — massing and scale;
3. Visual Gate B — intact/operational architecture;
4. Visual Gate C — historical/damage-state comparison;
5. Visual Gate D — final multi-angle/near-360 review;
6. mechanical/static validation;
7. the 100-point peak-quality rubric.

A render existing is not the same as a render being reviewed. Every gate must record
visible findings, corrections or explicit justifications.
