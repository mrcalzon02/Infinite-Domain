# OWS-001 Pass 4 — Program and Adjacency

## Orientation convention

The inherited site relationship remains useful and is retained for planning:

- **front / public approach:** low-Z side;
- **rear / freight-service side:** high-Z side;
- **west side:** preferred dirty-return/sanitation side;
- **east side:** preferred clean cold-stock/issue-support side.

This orientation is a planning convention for OWS-001 and must remain consistent through the fixed-camera review set unless Gate A proves the entire approach should change.

## Three circulation systems

The plan is organized around three primary routes plus one controlled dirty-material path.

### Public

`front entry -> vestibule/information -> issue counter OR return counter -> exit`

### Clean staff/service

`staff/service access -> receiving/batch check -> clean cold hold -> issue staging -> issue counter`

### Freight

`rear apron -> receiving -> clean stock` and `return consolidation -> rear dispatch -> backhaul`

### Dirty return

`return counter -> sanitation/inspection -> normal return consolidation OR local quality hold`

The clean staff route and dirty return route may meet at supervised decision points but may not share ordinary storage or work surfaces.

## Conceptual floor-band organization

The following is an adjacency diagram, **not final block coordinates**.

### Front band — public service

Approximate depth: 7–10 blocks.

From west to east:

1. return-facing public position;
2. central vestibule / information / queue;
3. issue/account positions;
4. customer-facing locker/pickup interface behind issue.

The facade must make the primary entry dominant while allowing the return function to be found without sending returned material across the clean issue queue.

### Middle-west — dirty-return cluster

Required chain:

`return handoff -> contained intake -> sanitation/inspection -> quality decision -> quality hold OR returned-crate consolidation`

The quality-hold bay should sit **after inspection**, not directly on the public threshold.

The D1 historical retrofit can add temporary markings, movable barrier logic, revised signage and one isolated equipment segment without altering the whole building into a containment facility.

### Middle-east — clean cold-chain cluster

Required chain:

`receiving/batch check -> clean cold hold -> issue staging / locker service aisle -> customer issue`

The clean cold-storage block should sit below or immediately adjacent to the roof mechanical plant so the vertical service relationship is visually obvious.

### Rear band — service and records

Required functions:

- freight receiving threshold;
- batch/temperature check;
- clean stock / short staging;
- returned-crate consolidation;
- rear dispatch/backhaul;
- supervisor/batch records;
- staff/service access.

The rear elevation should read as an operational service facade rather than a second public entrance.

## Recommended spatial hierarchy

### Primary public node

A front-center entrance volume with enough projection/setback to be visible in Gate A.

### Primary operational node

The cold-locker/issue interface should sit near the center-front/center-east of the plan so it can be visually understood from the public zone while remaining staff controlled.

### Narrative node

Return sanitation and quality hold should occupy the center-west service side where the D1 anomaly can be read as a localized operational problem.

### Evidence node

The supervisor/batch-record room should sit rear-center or rear-east, adjacent to receiving/stock decisions and accessible from the staff spine. It should not become an isolated treasure closet.

## Staff spine

A **minimum two-block clear route**, preferably three in the most active service section, should connect:

`supervisor -> receiving -> clean hold -> issue support`

with controlled branches to:

`sanitation -> quality hold -> return consolidation`.

This route is not a dungeon corridor. It should read as back-of-house workplace circulation through doorways, work zones and short service passages.

## Doors and thresholds

- main public entrance: double-width preferred;
- public issue/return handoffs: counters/openings, not unrestricted doors into service space;
- staff/service doors: single or double as function requires;
- rear freight opening: at least three blocks wide if represented as a loading door;
- quality hold: controlled door/opening, not decorative bars that trap no logical route;
- sanitation: controlled but routinely accessible to staff.

## External adjacency

The site needs more than a building shell.

### Front

- pedestrian approach from parking/street;
- identifiable entrance landing/canopy;
- small service-oriented rather than retail-merchandising frontage.

### Rear

- compact delivery/backhaul apron;
- crate/pallet staging aligned to the freight opening;
- service access toward roof/mechanical maintenance.

### Side

At least one side should visibly express operational infrastructure: service conduit/pipe route, returns-support entry, or screened mechanical relationship. All four facades cannot be generic blank donor walls.

## Adjacency rejection conditions

Pass 4 fails if the later floor plan:

- makes customers cross freight or sanitation routes;
- forces returned biological material through the clean locker hall;
- places quality hold before inspection;
- hides receiving on a side with no vehicle/service approach;
- places cold stock far from both receiving and locker issue;
- makes the supervisor/evidence room unrelated to stock/receiving decisions;
- leaves no practical maintenance path to refrigeration equipment;
- turns every zone into one open rectangular hall distinguished only by floor color.
