# Old World Audio Diary Book Sources

Canonical player-readable written-book payloads for the Continuity audio diary corpus. The authoritative Old World generator reads these sources, validates them against `kubejs/config/old_world_audio_diaries.json`, and reproduces their written-book pools in the paired evidence-chest loot tables. Runtime loot tables under `kubejs/data` are generated output, not the source of truth.
