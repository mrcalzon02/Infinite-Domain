## Blocking defect — principal staff/player vertical route is absent

**REVISION REQUIRED.**

Pass 8 explicitly requires a continuous usable principal staff/player stair-and-landing route:

`podium staff transition -> cultivation 1 -> cultivation 2 -> cultivation 3 -> upper cultivation/containment-capable floor -> roof/service crown`.

The r2 implementation does not provide that route.

The west core contains the repaired continuous **ladder**, which the Pass-8 plan defines as the secondary/egress system. The east core contains the freight/material-transfer abstraction and vertical service headers. No actual stair flight connects the production levels.

This is not a cosmetic preference. A high-rise agricultural institution cannot claim complete intact circulation when ordinary staff movement between production floors is represented only by an emergency ladder or by the freight/service shaft. The functional definition required distinguishable people/egress and production/service systems; Gate B must prove both before history or damage begins.

The floor slices reinforce the source finding: they show the repeated cultivation plates and east service handoff, but no principal stair system running through the tower.
