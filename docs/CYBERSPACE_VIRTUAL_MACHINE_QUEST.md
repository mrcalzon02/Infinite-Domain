# Cyberspace Virtual Machine Quest

Date: 2026-08-14

The Cyberspace progression branch is attached to the end of Cyberware Ascension
and requires the Era 8-gated Posthuman Stewardship quest. It contains two quests:

1. **The Virtual Machine, Since Nobody Wrote a Manual** requires twenty-one
   Virtual Machine Casings, one Virtual Machine Core, one Wrench, and one
   Terminal. Its description embeds the official construction diagram and gives
   explicit layer-by-layer assembly instructions.
2. **First Connection to Cyberspace** requires the player to use the Terminal and
   actually enter the Cyberspace dimension. Its text explains that the default
   Leave Cyberspace key is `C` and directs players who rebound it to Controls.
