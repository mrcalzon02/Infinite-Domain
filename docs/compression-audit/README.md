# Infinite Domain Compression Catalog

This catalog records every AllTheCompressed material family available to the current pack. It is the source list for converting foundational and era recipes to compressed-material costs.

- Material families: 199
- Compressed block IDs: 1791
- Available tiers per family: 1x through 9x
- A 1x block represents 9 ordinary units; a 2x block represents 81; each later tier multiplies the cost by 9.

The live item/block registry remains authoritative. This catalog records the compression relationships supplied by AllTheCompressed and should be regenerated whenever that mod version changes.
