# Wasteland Foraging

Common vegetation now supports the Era 0 scavenging and compost loop without replacing its vanilla behavior.

| Plant | Existing drop retained | Added scrap chance | Added self-drop chance |
|---|---|---:|---:|
| Fern | Wheat Seeds (12.5%, Fortune-compatible); guaranteed Fern with shears | 1% | 4% without shears |
| Dead Bush | 0-2 Sticks; guaranteed Dead Bush with shears | 1.5% | Existing shears behavior retained |

Fern and Dead Bush items are accepted by Ex Deorum barrel compost recipes, so a lucky self-drop becomes organic volume rather than decorative clutter.
