# Darknet data nodes

## Purpose

The Darknet now contains an actual mining loop for the six recovered-data items
used by Charles, quests, stores, and late-game recipes. Four non-craftable nodes
replace only the native Darknet foundation during generation. No node feature is
admitted to Cyberspace, the Overworld, the Nether, the End, or any mod dimension.

All four nodes require a Diamond-tier pickaxe. Their hardness, emission, depth,
frequency, and rewards increase together so the visual rarity progression also
communicates mechanical value.

| Node | Band | Generation | Primary recovery | Additional recovery |
| --- | --- | --- | --- | --- |
| Fragmented Data Node | Y=-24 to Y=1 | 11 attempts per chunk, vein size 8 | 2–5 Scraped Access Tokens, Darknet Extraction-sensitive | 30% Darknet Data Cache |
| Corrupted Data Node | Y=-40 to Y=-8 | 6 attempts per chunk, vein size 5 | 1–3 Darknet Data Caches, Darknet Extraction-sensitive | 1–3 tokens; 55% Encrypted Credential Bundle |
| Encrypted Data Node | Y=-55 to Y=-24 | 3 attempts per chunk, vein size 3 | 1–3 Encrypted Credential Bundles, Darknet Extraction-sensitive | one cache; 65% 1–2 Black ICE Kernels; 10% Zero-Day Archive |
| Root Access Node | Y=-63 to Y=-48 | one attempt per 24 chunks, vein size 2 | 1–2 Zero-Day Archives, Darknet Extraction-sensitive | 2–4 kernels; 2–4 caches; 12.5% Root Authority Key |

The deeper three tiers also contain premium Broker recoveries: Corrupted Nodes
have a 2% Ghost-Market Cipher chance; Encrypted Nodes have 7.5% Cipher and 1%
Black-Ledger Writ chances; Root Access Nodes have 25% Cipher and 7.5% Writ
chances. These independent bonus rolls are not multiplied by Darknet Extraction.

The Darknet Bedrock occupies Y=-64 beneath every new chunk. It is unbreakable,
has no loot table, and cannot host ordinary mob spawns. The 65 layers above it
remain the mineable native foundation targeted by the node features.

## Darknet Extraction

Darknet Extraction is a five-level pickaxe enchantment. It deliberately has no
global enchantment effect: only the four data-node loot tables inspect it, so it
cannot multiply vanilla ores, modded ores, mob drops, chests, or structure loot.

For every node, levels I–V apply Minecraft's native Fortune ore-drop formula to
the primary recovered-data stack. Higher levels can multiply that entire stack;
the special 30%, 55%, 65%, 10%, and 12.5% recovery rolls remain unchanged.

The enchantment supports pickaxes only and is mutually exclusive with ordinary Fortune
and Silk Touch. Efficiency, Unbreaking, and Mending remain compatible. It is a
rare-weight, non-treasure enchantment, so it can appear through enchanting tables,
enchanted-book loot, and librarian trades; its fifth level is intentionally
difficult, but possible, to roll directly.

## Art implementation

The production atlas is
`docs/art-direction/darknet-data-node-production-atlas.png`. It derives from the
established `docs/art-direction/darknet-content-reference.png` palette and maps,
left to right, to Fragmented, Corrupted, Encrypted, Root Access, and Darknet
Bedrock. The resulting game textures are 32×32 PNG files under
`kubejs/assets/kubejs/textures/block`. The exact built-in image-generation prompt
is stored beside the atlas as `darknet-data-node-production-atlas.prompt.txt`.

The original reference sheet's six item concepts are also implemented as
transparent 32×32 textures under `kubejs/assets/kubejs/textures/item`; the custom
items no longer borrow unrelated vanilla, Applied Energistics, or Cyberspace
icons. `scripts/generate_darknet_data_node_textures.ps1` regenerates all eleven
assets deterministically from the two checked-in source sheets.

Darknet Scrip, the Ghost-Market Cipher, and the Black-Ledger Writ use the related
`darknet-broker-items-reference.png` sheet and are regenerated by
`scripts/generate_darknet_broker_art.ps1`. Their economy and exact recovery odds
are documented in `docs/DARKNET_BROKER.md`.

## Loading and existing worlds

Block and item registration runs at startup, and flat-generator settings are
world data. A full game restart is required. The ore features affect newly
generated Darknet chunks only; this pack does not retro-convert an existing
Darknet, because none is expected to exist yet and automatic replacement could
overwrite structures or player work.
