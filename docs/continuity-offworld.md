# Continuity Off-World Corpus — Hero Build

Generated by `scripts/continuity_offworld.py`.

This is a single hand-authored landmark, not a corpus. It exists to prove the
Structure Rebuild System v2 pipeline — the `Template` authoring API plus
`structure_geometry_lint.py`'s six geometric checks plus the new
`structure_geometry_primitives_v2.py` primitives (`encased_stairwell`,
`ladder_shaft`, `backed_sign`, `wall_window`, `terrain_footing`, and
siblings) — generalizes to genuinely new content, not just wasteland
retrofits. Every primitive here was used on new content from the first block
placed.

It is **not** part of the 84-structure wasteland corpus
(`structure_library/corpus-manifest.json`'s counts are unchanged) and is
**not** folded into the Old World Narrative OWS numbering. It follows the
existing "alien" structure family's pattern instead: a single landmark NBT
with direct jigsaw/structure_set/template_pool worldgen registration, no
masters/variants split, since there is exactly one instance.

## Continuity Far-Side Redoubt

- 44×12×34 pressurized lunar contingency site belonging to Continuity, the
  containment-science network introduced in the Old World Narrative canon
  (`old_world_narrative/registry/lore_seed.json`,
  `structure_targets.json` OWS-051/052/053). Non-canon extension consistent
  with that identity: an off-world fallback site beyond the reach of
  whatever containment failure the Earth-side network exists to prevent.
- Sits on a lunar regolith apron with a footed foundation course, landing
  pad with rocket station/launch pad and corner antenna masts, and an
  airlock chamber gating the pressurized shell from the exterior.
- Interior program: command/monitoring room (desks, globes, radio, data
  bank, wall window onto the corridor), life-support systems bay (oxygen
  distributor, water separator, tanks, ladder to the roof), crew quarters
  (three beds, storage, an encased stairwell to the roof deck), and an
  archive vault (lectern, four loot chests, a bank of data-storage units) —
  Continuity's actual mission at this site.
- Roof: a solar array, a pillar-mounted antenna mast and a flag, laid out to
  clear both roof hatches (stairwell and ladder).
- Palette: vanilla plus the "stellaris" mod's real Moon block catalog —
  moon stone/brick/polished/cobble/pillar, steel plating, rocket
  station/launch pad, vacuumator, oxygen distributor, water separator,
  antennas, storage tanks/banks, globes, solar panels, flag and coal
  lantern. Every `stellaris:` block and blockstate property used was
  verified against the mod's actual registered blockstates by extracting
  and reading `assets/stellaris/blockstates/*.json` directly from
  `stellaris-1.21-neoforge-1.4.25.jar`, not guessed.
- Loot: reuses the existing `infinite_domain:chests/wasteland_data` and
  `infinite_domain:chests/wasteland_industrial` loot tables rather than
  inventing new unregistered IDs.
- Worldgen: `#stellaris:moon_biomes`, jigsaw `surface_structures` step,
  `random_spread` placement, spacing 72 / separation 28 chunks — wider than
  the alien family's Moon Meridian Monolith (spacing 54) since this is a
  larger landmark.
- Lint verification: 0 hard-fails and 0 review-flags across all six
  `structure_geometry_lint.py` checks (`structural_connectivity`,
  `stairs_ladders_signs`, `openings_wall_coupled`, `ground_plane`,
  `room_composition`, `damage_coherence`), confirmed both before saving
  (in-memory) and after a real `Template.save()` → disk reload →
  `positions_from_load_structure()` → re-lint round trip. 4,395 blocks
  placed, 3,073 of them modded.

## Pipeline verification notes

Two geometry bug classes were caught before the lint tool ever ran, purely
by manual coordinate tracing: a ladder's backing column silently
overwriting a fixture placed on the same wall face, and a rooftop
fixture grid overlapping a stairwell's roof hatch. The lint tool then
caught seven more findings, all one root-cause pattern (a prop placed one
block above its actual floor) plus one `backed_sign` call whose backing
landed in open air instead of on solid wall material — both classes the
tool is specifically designed to catch. All were fixed and reverified to
zero findings, then reverified again after a full disk round trip.
