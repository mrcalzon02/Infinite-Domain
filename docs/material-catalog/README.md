# Expanded Material Catalog

Generated directly from the item models in Basic Nether Ores and More Ores More Gems. This remains reproducible even when the last live registry capture predates those jars.

- Indexed item forms: 1171
- Inferred material families: 281
- Ore blocks: 178
- Metal ingots: 39
- Nuggets: 29
- Raw material forms: 87
- Storage or special blocks: 95

`expanded-material-items.csv` is the exact item-form index. `expanded-material-families.csv` groups likely related forms for recipe design. Inference is intentionally explicit and auditable because More Ores More Gems contains several unconventional and misspelled IDs.
