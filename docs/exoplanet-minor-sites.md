# Exoplanet Minor Sites

Generated by `scripts/generate_minor_exoplanet_sites.py`. Full per-site stats in
`docs/exoplanet-minor-sites-manifest.json`.

A third, lighter-weight tier alongside the "alien" ancient landmarks and the
"offworld" Continuity hero sites: small, quick-to-find points of interest that
multiply the number of discoverable structures per planet, at minimum 5x each
planet's prior total. Namespace: `infinite_domain:minor/<planet>_<kind>_<NN>`.

## The four kinds

Every planet draws from the same four generic site kinds, built by one shared
generator per kind so each variant is genuinely different (seeded per-variant
randomness drives footprint size, ruin/damage amount, light fixture, loot rolls,
door facing) rather than being a copy-paste reskin:

- **Waypoint** — a small way marker repeating the same five-rayed glyph as the
  major ancient landmarks, at breadcrumb scale. Reads as the same lost culture,
  just a minor site rather than a destination in its own right.
- **Wreck** — a small, recent crash: crumpled `stellaris` plating with random
  torn gaps, not ancient stone. On Jupiter this is a drifting hull fragment with
  nothing beneath it, floating the same way the Void Coliseum does.
- **Cache** — a low mound with a single buried two-block-tall room, entered by a
  roof trapdoor and ladder, holding one or two chests.
- **Debris field** — no building at all, just a scavengeable scatter of metal
  plate and cracked stone with one half-buried chest.

## Distribution

- **Moon**: 3 waypoint, 3 wreck, 3 cache, 3 debris.
- **Mars**: 3 waypoint, 3 wreck, 2 cache.
- **Venus**: 2 waypoint, 3 wreck, 3 cache.
- **Mercury**: 2 waypoint, 2 wreck (no cache/debris — kept to the two kinds
  that read cleanly against the fire-land biome without adding a fourth
  redundant beacon).
- **Jupiter**: 2 waypoint, 2 wreck (void-only kinds; cache and debris don't
  make sense with no ground to bury into or scatter across).

## Loot

Each `(planet, kind)` family shares one loot table
(`infinite_domain:chests/minor/<planet>_<kind>`) built entirely from items
already registered by the space-industry catalog or vanilla/`stellaris` items —
no new custom items were added for this tier, consistent with how the existing
Continuity crash sites already handle minor loot.

## Required runtime gate

None of these 36 sites have been tested in a live world. Structural checks only
cover: in-bounds placement, exactly one guaranteed chest per site, and nothing
solid directly above any chest. Before treating this tier as finished, spot-check
a handful of each kind on fresh planet worlds for jigsaw placement, terrain
blending (surface kinds) or void float behavior (Jupiter), and walkable interiors.
