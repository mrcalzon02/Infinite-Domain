# LAST DAYS: Infinite Domain

Target: Minecraft 1.21.1 / NeoForge. Resource-pack format: 34.

This folder is the editable source pack. `LAST_DAYS_1_20_1.zip` remains the untouched upstream archive; build/distribution ZIPs use the `LAST_DAYS_INFINITE_DOMAIN_1.21.1` name.

## Source layers

1. Upstream LAST DAYS 1.20.1 assets (visual baseline)
2. `kubejs/assets` (instance overrides; highest priority for matching paths)
3. First-party mod assets from `packdev/*/src/main/resources/assets` (bundled here as conversion coverage)
4. Minecraft 1.21.1 vanilla assets for paths not covered above (structural placeholders awaiting LAST DAYS conversion)
5. Original texture assets from every installed texture-bearing mod JAR, added only where the preceding layers do not already provide an override

## Total-conversion conventions

- Keep each mod's namespace and exact asset path.
- Keep compatibility textures at the exact dimensions of the installed source asset. Author directly at native resolution; enlarged nearest-neighbor sheets are review aids only and oversized generated masters must not be reduced into production textures.
- Preserve animation `.png.mcmeta` beside its texture.
- Prefer complete visual families (block, item, GUI, particles, entity) over isolated recolors.
- Use dirty industrial materials, oxidized metal, worn paint, restrained emissives, and strong silhouette readability.
- Do not edit the upstream ZIP. Work in this folder, then rebuild the Infinite Domain ZIP.
